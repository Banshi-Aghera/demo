# Introduction

## 1.1 Overview

**SocietyCart** is a Flutter-based e-commerce application designed specifically for Indian apartment societies. The application provides a convenient platform where residents can browse products, add items to their cart, place orders, make payments, and manage their purchases.

The system consists of a **customer application** available for Android, iOS, and Web, along with an **admin panel** available on Web and mobile platforms.

SocietyCart provides normal e-commerce functionality along with community-focused features such as:

- **Neighbour Drop**
- **Neighbour Lending**
- **Group Buy**

These features are designed to provide additional ways for residents within a society to interact and share products or purchasing opportunities.

## 1.2 Purpose

The main purpose of SocietyCart is to provide a simple and convenient shopping platform for apartment society residents.

The application allows users to:

- Register and log in securely.
- Join their apartment society.
- Browse product categories.
- Search for products.
- View product details and reviews.
- Add products to the cart.
- Save products to a wishlist.
- Apply coupons.
- Place orders.
- Pay using Razorpay or Cash on Delivery.
- Track order status.
- Request returns.
- Download GST invoices.
- Receive order notifications.

## 1.3 Admin Panel

SocietyCart also provides a complete admin panel for managing the e-commerce platform.

Administrators can manage:

- Products
- Categories
- Banners
- Orders
- Users
- Apartment societies
- Coupons
- Delivery settings
- Business information
- Reports

The admin dashboard also provides information such as revenue, orders, new users, top products, and low-stock products.

## 1.4 Technology

The application is developed using **Flutter** and uses **Firebase** for backend services.

Major technologies include:

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Firebase Cloud Functions
- Razorpay
- Node.js

The application supports Android, iOS, and Web platforms.

## 1.5 Project Status

The project is divided into seven phases.

Currently, **Phases 1–4 are completed**:

1. Authentication and roles
2. Catalog, search, cart, and wishlist
3. Checkout, payments, orders, returns, invoices, notifications, and reviews
4. Complete admin panel

The remaining phases are:

5. Neighbour Drop
6. Neighbour Lending
7. Group Buy

## 1.6 Conclusion

SocietyCart combines standard e-commerce functionality with apartment-society-focused features. It provides residents with a single platform for shopping and managing orders, while administrators can manage products, users, societies, orders, payments, coupons, and reports through the admin panel.
